## 📂 Featured Project

### Healthcare Operations Analytics Dashboard

**Python · Streamlit · Pandas · Plotly**

An interactive dashboard for exploring healthcare infrastructure across India —
hospital bed capacity, workforce distribution, emergency readiness, and regional
coverage. Built to turn unstructured public healthcare data into something a
planner can filter, compare and act on.

Built during the Infosys Springboard Virtual Internship 6.0
under the mentorship of Mousami Shrivastava.

**Features**
- Infrastructure analysis across beds, hospital types and care categories
- Emergency readiness assessment
- Geographic coverage insights with region-level comparison
- Interactive filtering and data exploration
- Downloadable dataset for further analysis

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Charan1845/-Infosys-Springboard-Virtual-Internship-6.0)
